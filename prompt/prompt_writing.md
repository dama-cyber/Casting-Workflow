# 写作要求 — 正文阶段

## 阶段目标
完成短篇正文，对话占比 ≥40%，爽点密集，朱雀不可反查。

## 正文核心规则（阶段特有）
- 对话密度 ≥40%，关键场景 ≥60%；每段对话至少完成一件事（功能化）
- 每章至少一个情绪爆发点；章节标题用番茄风 4-8 字小标题，不用"第X章"
- 每章开头避免"XX走进房间"类模板句式；每章结尾必须有钩子
- 动作描写优先于形容词堆砌；超过 300 字纯叙述段落需打断（插对话/动作）
- 给角色加特有口癖 / 方言 / 句式偏好，制造辨识度；故意留 20% 空白给即兴发挥

## 爆款节奏（阶段特有）
- 爽点前置：开局即高潮，前三章解决一个核心生存 / 面子危机
- 情绪曲线：紧张→释放→更紧张→更大释放→心疼→虐→反转→治愈
- 反转路线图：至少 3 次反转，小→中→大递进

> 全局约束（反AI检测技巧 / 禁止清单 / 原创红线 / 引号策略）见 COMMON.md，已由系统自动注入，请勿重复书写。

## 输出要求
- 直接输出正文，无需解释
- 保持人设与世界观一致，角色名全程归一化
