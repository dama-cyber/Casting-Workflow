# 扩写铺陈 — 扩写阶段

## 阶段目标
对正文中较薄弱的场景深度扩写，增加细节与情绪铺垫。

## 要求（阶段特有）
- 识别正文"留白"点（可扩写的薄弱场景）
- 扩写后不破坏原有节奏，不改变原有人设
- 扩写段落保持对话密度 ≥40%
- 用动作 / 感官细节填充，而非形容词堆砌

> 全局约束（反AI检测技巧 / 禁止清单 / 原创红线）见 COMMON.md，已自动注入。

> 注：自动扩写闭环的「追加模式」指令由 build_full_prompt 代码注入（append_mode=True），本模板无需改动。

# 续写扩展 — 续写阶段

## 阶段目标
基于已有正文向后续写，扩展故事长度。

## 要求（阶段特有）
- 严格遵循已建立的人设与世界观
- 延续正文的叙事节奏与对话风格
- 新增内容必须包含至少 1 次反转和 1 个爽点
- 章节结尾必有钩子，与已有正文衔接自然

> 全局约束见 COMMON.md，已自动注入。
