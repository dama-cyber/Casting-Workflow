# 优化质检 — 优化阶段

## 阶段目标
全篇质检，发现问题并标记；本阶段只标注不重写。

## 检查项（阶段特有）
- 角色名是否全程一致（归一化检查）
- AI模板词是否清零、对话密度是否达标（≥40%）
- 章节钩子是否到位、爽点节奏是否符合预期
- 是否有 >300 字纯叙述段落需打断加入对话 / 动作
- 连续 3 句以上相同句式、书面语对话

## 输出
以清单形式输出：问题位置 + 问题类型 + 修改建议（不输出全文）。

> 全局约束（反AI检测技巧 / 禁止清单 / 原创红线）见 COMMON.md，已自动注入。

# 润色打磨 — 润色阶段

## 阶段目标
在优化基础上对文笔细节精细打磨，提升流畅度与阅读体验。

## 检查项（阶段特有）
- 句式变化：长短句交替，避免连续 3 句相同结构
- 用词多样性：替换重复形容词 / 副词为更精准表达
- 节奏感：紧张场景用短段，抒情场景用中段
- 对话自然度：逐句朗读检查，删除"书面语对话"
- 标点密度：符合口语节奏（！/句、，/句参考 corpus 统计分布）

## 输出
输出润色后的全文（或按章节），保留原人设与节奏。

> 全局约束见 COMMON.md，已自动注入。
