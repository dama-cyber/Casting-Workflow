# 拆文方法论知识库（deconstruction）

本目录由写作方法学知识库（Casting-Workflow 自有方法论层）的拆文方法论迁移提炼，是「看懂别人爆款，才能写自己爆款」的方法论底座。

**拆文** = 把一部小说做结构化拆解，提取：人设架构、爽点设计、节奏控制、情绪模块、钩子技法、写作手法，作为写作时的对标资产。落地由 `tools/story_analyze.py` 驱动，产物落盘 `analysis/{书名}/`（独立于 `corpus/`，防污染）。

## 文件
- `deconstruction-notes.md` — 拆书方法论：六原则 / 条件框架提取法 / 桥段词表 / 三幕式 / 题材实战 / 人设塑造。

## 与其它目录的关系
- 拆出的「情绪模块 / 节奏」喂给 `plot-emotion/` 与 `story-write`；
- 拆出的「人设」喂给 `character/`；
- 拆出的「钩子技法」喂给 `hooks/`（已在 T03 先行建好）。

> 本目录只讲「怎么拆」，不重复写作侧规则（去 AI 味见 `anti-ai/` 导航与 `prompt/COMMON.md`）。
