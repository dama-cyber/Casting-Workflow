# 拆文方法论速查（提炼自写作方法学知识库的拆文分析）

> 配合 `tools/story_analyze.py` 与 `material-decomposition.md` 使用。这里只提炼可复用的「怎么拆」，不复制剧情内容。

## 一、六原则
有目的 / 有方法 / 拆出理论 / 摒弃好恶 / 扬长避短 / 拆自己喜欢的书。

## 二、拆书流程
概括一句话 → 识别结构单元（起承转合，递进扩大） → 抽离框架 + 情绪链条 → **借鉴框架非抄内容**。

- **条件框架提取法**：剧情提炼为条件（如「展露部分天赋 + 两方势力争夺 + 信息差制造慧眼识珠」），替换人物/背景/金手指后复用，保留情绪相似。
- **抽象五步法**：概括 → 拆为信息团（情绪转折点） → 按上行/下行/转折归类 → 提取通用条件框架 → 用素材填充。
- **感情线双标法**：同一件事（如送可乐）前后态度截然不同 + 主角不清楚 → 制造拉扯。

## 三、核心情绪控制
- 自检：文本是否偏离核心梗、是否出现只服务表达欲却不服务读者期待的段落；偏离=留存风险，不是主观评价。
- **刀人原则**：刀人是手段非目的，对笔力要求极高；必须刀时埋伏笔留弥补空间，项目无足够铺垫/补偿/情绪回收时不动重要角色；悲情强度由目标平台近期样本校准。
- **强情绪校验**：若平台近期高频强情绪文，记录触发情绪/释放节奏/噱头位置/留存证据；无样本时不作为硬性趋势。

## 四、题材边界与核心梗
- 核心梗 = 读者需求；偏离=抛弃读者（核心对比消失 / 机制不升级 / 题材串味 / 后期三观偏离都会掉读者）。
- **核心梗四维度**（以「逆袭系统」为例）：① 任务数量 ② 奖励难度 ③ 等级阶层+隐藏触发 ④ 奖励触发新戏剧性任务。仅用前两点戏剧性快速耗尽，四点结合才持续。

## 五、结构设计与节奏
- **情绪拉扯工具**：熟悉套路（选套路→搞人设→填剧情）；期待断掉续上（引入新角色/事件重新拉起）；装逼打脸底层（鄙视链+人际舞台+正反传播）；复合型配角（主角「白手套」：替声+绝对支持+搞笑）。
- **望远镜拉期待法**：倒计时结构（发现→观测→打捞→失败→坠落），读者都知道子弹会射向主角 → 巨大期待。
- **分卷节奏**：每二三十万字一卷，有明确核心与目标；卷内多线头打破线性；「起」必须抛钩子；卷尾为下卷埋线。

## 六、卖点循环设计（可复制）
- **完美循环**：小号装逼打脸赚好处 → 做主线任务 → 获奖励 → 提升武力 → 新地图装逼 → 循环；每次内容不同 + 情感进展拉住期待 + 最终暴露小号身份=逼兜回主角。
- **信息密集循环**（轮回流）：每轮回=完整故事，力量体系不崩即可无限拉长。
- **直播流循环**：目标（确定性预期）+ 对抗（短平快）+ 阶段性（任务升级）+ 整活正反馈。

## 八、对标书选择
- 错误：只拆一本 / 只拆唯一头部爆款（依赖不可复制的作者品牌）/ 跨网站对标（读者群体不同）。
- 正确：广泛收集同题材样本 → 定方向 → 定参考书 5-10 本（同平台同题材、数据稳定、非唯一头部）→ 定对标书。

## 九、三幕式（抽象拆书法）
- 第一幕-建立：暗示矛盾 → 主角+金手指 → 惊人意外 → 情绪上下拉扯 → 主线确立。
- 第二幕-对抗：新世界 → 更强对手 → 中点反转 → 情绪拉扯（下行后必有上行）。
- 第三幕-决战：线索收束 → 矛盾极限 → 关键选择（体现人物弧光）→ 决战+主题升华。

## 十、拆书实操
- **情绪折线图**：横轴章节、纵轴情绪正负；控制「富有戏剧性的信息团」出现速度。
- **逐段功能标注**：铺垫/转折/高潮/过渡，追踪情绪走向、困境设计、伏笔衔接；输出可复用框架，禁止复制剧情。
- **影视拉片**：人物态度转变最能体现情绪；打斗间穿插反应但控制字数；每个动作段带出情绪变化。

## 十一、题材实战要点
- 历史文=类同人写法；书名「朝代+开局事件」；核心梗=先知先觉震惊名人+改变历史。
- 军事文=煽情+身临其境；核心矛盾=国与国/信仰。
- 种田/脑洞=密集小爽点（收藏/能力/面板/震惊）；面板细致。
- 直播流=目标+对抗+阶段性+爽点（先告诉读者打算怎么装逼，再装更大的）。
- 重生流=天然期待感；前世被辜负→这一世报复；爽点可重复但每次形式不同。
- 两界穿梭=书名即卖点；核心梗=在A世界低调用B世界资源；长生凡人流=时间尺度大+配角代际更替。

## 十二、人设塑造
- 第一章立人设：小事件展示性格 → 贴标签确立；紧急事件快速带入；女角色第一步反应体现性格。
- 日常体现人设：重复符合人设的行为；配角功能化（嫉妒型：得意→嫉妒；崇拜型：质疑→佩服），情绪转变要写出。
- 开篇逻辑：被动入局 → 交流了解世界观 → 陷入困境 → 明确目标 → 展示金手指 → 通过金手指收获。
