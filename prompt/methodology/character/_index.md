# 人设知识库（character）

> **来源**：写作方法学知识库（Casting-Workflow 自有方法论层）的 character 方法论文档（character-basics / character-design-methods / character-relations）。
> **迁移方式**：逐字迁移方法论参考文档（与 corpus 无关，不触红线）。
> **用途**：建人设、配角、反派、感情线时按需取用；对应 `run_pipeline.py` 的人设 阶段可由 `story-write` 注入。

## 文件

| 文件 | 内容 |
|---|---|
| `character-basics.md` | 人设基础（身份/特质/动机/缺陷） |
| `character-design-methods.md` | 设计方法（成长弧/反差/功能位） |
| `character-relations.md` | 关系网设计（亲情/爱情/友情/敌对/师生/主从/利益） |

## 召回原则

- 建主角 / 反派 → `character-basics` + `character-design-methods`
- 搭关系网 / 感情线 → `character-relations`

> 与 `deconstruction/` 拆出的人设分析互补：本目录讲「怎么建」，拆文库讲「别人怎么建」。
