# 段落 / 小节钩子与留白

> **来源**：写作方法学知识库（Casting-Workflow 自有方法论层）的 hooks-paragraph 与 short-format 方法论文档（提炼）。
> **用途**：写单段 / 单节、控制阅读节奏、在段落层面制造「想往下读」的牵引时加载。

## 段落钩子是什么

段落钩子不是章尾大钩子，而是**每一段结尾留给下一段的牵引力**——一句没说完的话、一个刚出现的反常细节、一个被打断的动作。读者读完一段，本能地想读下一段。

## 常用段落钩子手法

| 手法 | 做法 | 示例 |
|---|---|---|
| 未完成动作 | 段尾停在动作进行中 | 「他刚把钥匙插进锁孔，门里传来一声轻响。」 |
| 反常细节 | 段尾抛出一个不合常理的东西 | 「桌上多了一只杯子。没人进来过。」 |
| 一句话悬念 | 段尾一句让读者疑问的话 | 「她认出了那个声音。不该是她的。」 |
| 感官断点 | 用声音 / 气味 / 触感收段，制造延续 | 「走廊尽头有脚步声。很慢。」 |
| 转折落点 | 段尾一个反预期的小反转 | 「他以为赢了。直到看见自己的影子多了一只手。」 |

## 留白技巧

- **不写尽**：情绪高潮后留半拍冷却，用动作 / 物件收住，不补定性评价。
- **不解释**：因果只从角色动作 / 对话 / 反应里让读者自己拼。
- **短段成段**：爆点 / 反转 / 恐惧重拍可单句成段；铺垫 / 空间 / 因果承接应并回同一镜头，忌通篇同长度或碎成提纲。

## 段长节奏（反 AI 腔关键）

- 一段通常只承载一个动作、一个信息变化或一组紧密相关的反应。
- 长短交错：打斗 / 冲突段更短（3–15 字单句可用）；日常 / 描写 / 推理段可稍长，但朗读不卡、信息不过载。
- **忌**：连续多段同一长度；为凑短碎成提纲；或通篇长句压住节奏。

## 段落钩子自检

- [ ] 关键段结尾是否有「牵引下一段」的力（未完成的动作 / 反常细节 / 一句话疑问）
- [ ] 爆点 / 反转段是否用了短句 / 单句成段
- [ ] 铺垫段是否并回同一镜头，没有碎成提纲
- [ ] 是否有长短交错，而非连续同长度
- [ ] 留白处是否没补定性评价（「他终于明白……」式总结已删）
