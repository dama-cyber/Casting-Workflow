# 钩子方法论目录（hooks）

> **来源**：写作方法学知识库（Casting-Workflow 自有方法论层）的 hooks 方法论文档（`hooks-chapter.md`、`hooks-suspense.md`、`hooks-paragraph.md`，另有短篇版 `hooks-*.md`）。
> **迁移方式**：提炼为方法论文档。保留决策路由、钩子类型与实战模板，去除 LLM 调用细节。
> **用途**：写每章开头 / 结尾、制造悬念、设计段落钩子时加载。

## 文件导航

| 文件 | 内容 | 调用时机 |
|---|---|---|
| [chapter.md](chapter.md) | 章首 / 章尾钩子选择与 13+7 式 + 爽点公式 | 写章首 / 章尾时 |
| [suspense.md](suspense.md) | 悬念钩子设计与「未解之谜」维持 | 制造中长期悬念、埋伏笔时 |
| [paragraph.md](paragraph.md) | 段落 / 小节钩子与留白技巧 | 写单段 / 单节、控制阅读节奏时 |

## 通用原则

- **钩子约 100 字**，点到即止，不拖沓；章尾钩子约 100 字即可显著提升完读率。
- **连续两章不用同一种钩子**；钩子强度须与章节阶段匹配（日常章不必强钩子）。
- **章首前 100 字必须有钩子**（非风景 / 天气 / 背景开头）。
- 钩子只服务「让读者想翻下一页」，不替代情节本身。

## 质量检查（每章）

- [ ] 章首前 100 字有钩子（非风景 / 天气开头）
- [ ] 章尾有让读者想翻下一页的东西
- [ ] 钩子强度与章节阶段匹配
- [ ] 连续两章不用同一种钩子
- [ ] 钩子约 100 字，点到即止，不拖沓
