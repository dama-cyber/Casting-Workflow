# 章级钩子：章首 / 章尾钩子选择与写作

> **来源**：写作方法学知识库（Casting-Workflow 自有方法论层）的 hooks-chapter 方法论文档（提炼）。
> **用途**：写每章开头或结尾时加载。先看决策路由选类型，再套模板。

## 决策路由

### 章尾钩子：根据本章情绪选类型

| 本章情绪 / 阶段 | 推荐钩子 | 为什么 |
|---|---|---|
| 悬念 / 未知 | 突然揭示 / 神秘物品 / 留白 | 激发好奇 |
| 紧迫 / 危机 | 紧急危机 / 倒计时 / 未完成动作 | 制造焦虑 |
| 反转 / 真相 | 身份反转 / 隐藏含义 / 回声 | 颠覆认知 |
| 情感 / 关系 | 两难抉择 / 承诺威胁 / 情感转折 | 拉扯情绪 |
| 系统文特有 | 系统激活 / 选择型 | 期待金手指 |
| 氛围 / 日常 | 意象钩子 / 离奇消失 / 信息差 | 暗流涌动 |

### 章首钩子：根据开篇策略选类型

| 开篇策略 | 推荐钩子 | 为什么 |
|---|---|---|
| 直接冲击 | 未完成动作开局 / 倒计时开局 | 即时紧迫感 |
| 制造好奇 | 悬念对话 / 闪前碎片 / 神秘独白 | 信息差驱动 |
| 对比冲击 | 反差场景 / 意象预示 | 反差吸引 |

### 章节阶段与钩子强度

| 故事阶段 | 推荐类型 | 强度 |
|---|---|---|
| 第 1 章 | 系统激活 / 截断 / 危机升级 | 必须强 |
| 2–3 章 | 选择 / 信息差 / 情感转折 | 强 |
| 中期日常 | 对话悬念 / 信息差 / 身份即将揭露 | 中 |
| 高潮前 | 危机升级 / 悬念预知 | 强 |
| 大结局 | 时间跳跃 / 情感转折 | 收束 |

## 章尾钩子 13 式（公式 + 思路）

| # | 名称 | 公式 | 思路 |
|---|---|---|---|
| 1 | 突然揭示 | 抛出改变全局的信息 | 读者原以为的秩序被一句话改写 |
| 2 | 紧急危机 | 下章必须回应的紧迫威胁 | 「裂缝在扩大，灵石还差三块」 |
| 3 | 未完成动作 | 动作被新变量打断 | 「他刚伸手，手腕忽然被人扣住」 |
| 4 | 身份反转 | 身份真相偏离读者预期 | 名字与「已故」档案冲突 |
| 5 | 两难抉择 | 被迫在两个坏选项中选 | 「签了公司保住，但他得进去」 |
| 6 | 神秘物品 | 重要但含义未知的物件 | 钥匙 + 字条「你欠我的」 |
| 7 | 倒计时 | 时间不够用 | 「医生说还有三个月，那是两个月前」 |
| 8 | 承诺 / 威胁 | 有人宣布行动意图 | 「今晚十二点前，我会告诉所有人」 |
| 9 | 离奇消失 | 不可能的消失 | 手铐在，人没了，门没开过 |
| 10 | 隐藏含义 | 表面正常，实际暗藏信息 | 「你和妹妹真像」——可她是独生女 |
| 11 | 意象钩子 | 反复出现的意象发生变化 | 枯了一月的茉莉突然冒花苞 |
| 12 | 回声钩子 | 章尾呼应开头，关键细节变了 | 同句收尾，但「她的手攥得更紧了」 |
| 13 | 留白钩子 | 只展示反应，不揭示发生了什么 | 「他看了信。脸色变了。什么也没说」 |

## 章首钩子 7 式

| # | 名称 | 公式 |
|---|---|---|
| 1 | 悬念对话开局 | 直接从意味深长的对话开始 |
| 2 | 闪前碎片 | 先给结果碎片，再回正常叙事 |
| 3 | 倒计时开局 | 开头就建立紧迫感 |
| 4 | 神秘独白 | 第一人称诡异内心独白 |
| 5 | 反差场景 | 两个截然不同的场景并列 |
| 6 | 未完成动作开局 | 动作进行中被截断 |
| 7 | 意象预示 | 用环境意象暗示即将发生的事 |

## 章尾实战模板（速写骨架）

- **系统激活型**：最低谷之际 → 感官描写 → 叮！【系统名，正式启动】。
- **悬念预知型**：冷静看着对方嚣张 →「继续吧 / 慢慢来」→ 预告反转不透露细节。
- **截断型**：一个小动作 → 剧烈反应 → 震惊 / 疑问，章末不给答案。
- **选择型**：【选择一：诱人 / 代价】+【选择二：另一诱人 / 另一风险】，章末不给出选择结果。
- **危机升级型**：突然声响 / 动作 → 新威胁出现 → 主角恐惧 / 紧迫反应。
- **身份即将揭露型**：旁观者突然提出疑问 / 发现线索 → 暗示真实身份 → 主角暗暗紧张。
- **情感转折型**：对方表情 / 态度突然大变 → 出人意料的示弱 / 请求 → 戳中软肋的话。
- **信息差型**：自我怀疑 / 感慨 → 一个意象 / 比喻 → 暗示即将改变但不明说。
- **对话悬念型**：「提出请求前半句」→ 回应 → 意想不到的后半句（非读者预期）。
- **时间跳跃型**：精确 / 模糊时间标记 → 出人意料结果 → 暗示过程的一句话。

## 三种速写章末钩子

- **收获预告型**（副本 / 任务尾声）：当前行动接近完成 → 暗示即将获得的奖励 → 一句话暗示奖励更大。
- **反派逼近型**（铺垫段结尾）：主角当前状态 → 暗处 / 远方反派的某个行动 → 暗示将影响主角。
- **行动预告型**（装逼 / 打脸前）：主角做出决定 → 一个准备动作 → 暗示即将发生的行动，不写结果。

## 爽点与看点设计规则

### 爽点核心公式

爽点 = 两个逻辑的冲突点：大众逻辑（对手不可战胜 → 恐惧 / 绝望） vs 主角逻辑（正好手痒 / 轻描淡写）。落差越大 → 爽点越爽。

### 爽点三要素

| 角色 | 操作 |
|---|---|
| 吃瓜群众 | 用议论吹高对手逼格 → 震惊反应完成打脸升华 |
| 对手 | 嚣张到让读者恨 → 被打脸时才爽 |
| 主角 | 铺垫时低调 → 释放时干脆 |

看点 = 吊起读者期待；爽点 = 满足期待。一一对应：前面铺垫多少，后面爽点就有多少。

### 装逼打脸节奏

| 阶段 | 公众期（5 章循环） | VIP 期 |
|---|---|---|
| 人设 | 1 章 | 1–2 章 |
| 铺垫 | 2 章 | 5 章 |
| 打脸 | 1 章 | 1–2 章 |
| 善后 | 1 章 | 1 章 |

**关键**：前置小无敌（打脸前把道具 / 人物 / 实力准备好）；铺垫比打脸更重要；打脸对象层级决定爽感层级（路人甲震惊不叫爽，有分量的人震惊才叫爽）；章末钩子约 100 字即可显著提升完读率。
