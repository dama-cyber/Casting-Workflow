# 题材正文提示卡索引（genre-prose-cards）

> **来源**：写作方法学知识库（Casting-Workflow 自有方法论层）的 genre-prose-cards 方法论文档（32 个独立卡 + `genre-prose-cards.md` 索引）。
> **迁移方式**：逐字迁移源 `genre-prose-cards/` 下 32 张题材卡（方法论参考文档，与 corpus 无关，不触红线）；保留来源标注，仅供写作侧按题材召回校准「题材味」，绝不出现在正文里。
> **用途**：写正文阶段按题材召回 1 张卡，校准「题材味」。

## 三件套使用原则

正文写作采用**三件套**：`通用正文要求 + 单题材正文提示卡 + 本书文风`。

- **通用正文要求**：严格消费细纲，按情节点预算写，缓慢推进，严禁提前写后续剧情；写完做字数、钩子、禁用词、退化校验。
- **题材卡**：只管题材层稳定核心——世界观 / 生活逻辑、读者期待、核心爽点 / 情绪、常见场面、常见钩子、禁止漂移。
- **本书文风**：只管句长、标点、潜台词、锚点片段、笔调；不覆盖题材卡，也不覆盖 `剧情/情绪模块.md` / `剧情/节奏.md`。

**冲突优先级**：章节细纲与连续性 > 情绪 / 节奏权威 > 题材卡 > 本书文风 > 通用技巧。

## 召回规则

1. 先读 `设定/题材定位.md`，确认主题材、目标平台、性向频道、主对标书和核心梗。
2. 先查本索引匹配题材，再只读取 `genre-prose-cards/{题材}.md` 这一张卡；**不要**把整套题材卡全部加载进 prompt。
3. 跨题材时：主题材读 1 张完整卡，辅题材读 1 张并只摘 1–2 条「常见场面 / 禁止漂移」。
4. 高置信卡直接可用；中置信卡需结合本书对标 / 细纲对照；低置信卡只能兜底，须标注低置信并优先补同题材对标。
5. 每章传给写作层的正文卡只保留本章相关条目（推荐 120–300 字）：题材限制、核心逻辑、读者期待、核心爽点 / 情绪、正文落点、前中后期打法、场景颗粒、禁止漂移、本章取舍、卡片置信度。
6. **题材卡只在写作层内部校准题材味，绝不出现在正文里**。

## 题材卡写法原则（九件事）

每张卡必须回答：题材核心、主线目标、冲突发动机、爽点定位、常见情绪转化、场景颗粒、正文落点、前中后期打法、禁止漂移。不要把通用方法论硬套进所有题材。
