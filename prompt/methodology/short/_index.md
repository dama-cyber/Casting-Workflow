# 短篇专属知识库（short）

> **来源**：写作方法学知识库（Casting-Workflow 自有方法论层）的 short 方法论文档。
> **迁移方式**：逐字迁移方法论参考文档（与 corpus 无关，不触红线）。
> **用途**：写 1–2 万字短篇时按需取用；对应 `run_pipeline.py` 的短篇模式（若有）或 `story-write` 短篇辅助。

## 文件

| 文件 | 内容 |
|---|---|
| `short-craft.md` | 短篇写法底座 |
| `short-format.md` | 短篇格式规范（小节标记 / 段间单换行 / 对话引号） |
| `short-deslop.md` | 短篇去 AI |
| `genre-writing-formulas.md` | 题材写作公式 |
| `genre-writing-techniques.md` | 题材写作技巧 |
| `genre-styles/` | 4 个短篇题材风格卡：复仇打脸 / 宅斗宫斗 / 总裁豪门 / 追妻火葬场 |
| `hooks-chapter.md` `hooks-paragraph.md` `hooks-suspense.md` | 短篇章首/章尾/悬念钩子 |
| `output-contract.md` | 输出契约 |
| `quality-checklist.md` | 质量清单 |
| `reversal-toolkit.md` | 反转工具包（短篇版） |
| `villain-and-reveal.md` | 反派与揭示 |
| `writing-workflow.md` | 写作工作流 |
| `dialogue-mastery.md` | 对话精通 |
| `emotional-methods.md` | 情绪方法（短篇版） |
| `banned-words.md` | 禁用词 |
| `cross-book-recall.md` | 跨书召回 |

## 召回原则

- 开短篇 → `short-craft` + `short-format`
- 定题材 → `genre-styles/{题材}.md` + `genre-writing-*`
- 埋反转 → `reversal-toolkit` + `villain-and-reveal`
- 自检 → `short-deslop` + `quality-checklist`

> 短篇正文为单文件 `正文.md`（不切章），不产 `追踪/` `大纲/` `正文/` 等长篇目录。
