# 情节情绪系统知识库（plot-emotion）

> **来源**：写作方法学知识库（Casting-Workflow 自有方法论层）的 plot-emotion 方法论文档（plot-emotion-system / reversal-toolkit / outline-* / plot-* / emotional-*）。
> **迁移方式**：逐字迁移方法论参考文档（与 corpus 无关，不触红线）。
> **用途**：设计大纲、爽点、反转、节奏时按需取用；对应 `run_pipeline.py` 的 大纲 / 细纲 / 正文 阶段可由 `story-write` 注入。

## 文件

| 文件 | 内容 |
|---|---|
| `plot-emotion-system.md` | 情节情绪系统总览 |
| `reversal-toolkit.md` | 反转工具包（身份/动机/阵营/信息/命运类反转） |
| `outline-methods.md` | 大纲方法 |
| `outline-conflict.md` | 大纲冲突设计 |

| `outline-structure-theory.md` | 大纲结构理论 |

| `plot-frameworks.md` | 情节框架 |
| `plot-special-topics.md` | 情节专题 |
| `emotional-arc-design.md` | 情绪弧线设计 |
| `emotional-methods.md` | 情绪方法 |

## 召回原则

- 写大纲 / 卷纲 → 召回 `outline-*` + `plot-core-methods`
- 设计反转 → 召回 `reversal-toolkit`
- 设计情绪节奏 / 爽点 → 召回 `emotional-*` + `plot-emotion-system`

> 本库为知识层；确定性拆文骨架由 `tools/story_analyze.py` 生成，LLM 拆文流水线见 `tools/story_analyze.py`。
