# 写作方法学知识库（methodology）

> **来源**：写作方法学知识库（Casting-Workflow 自有方法论层）。
> **迁移方式**：本目录为**方法论文档提炼**，非逐字复制大模型规则。每条均保留来源标注（源文件见各子目录 `_index.md`）。
> **用途**：作为 Casting-Workflow 创作管道（`run_pipeline.py` 的 人设 / 大纲 / 细纲 / 正文 等阶段）的「方法论补给」。对应阶段的提示词（`prompt/prompt_*.md`）可按需注入本知识库的题材卡 / 钩子 / 情节情绪工具，丰富创作手段。
> **与 `config/`、`prompt/COMMON.md` 的关系**：去 AI 味规则已由 `config/anti_ai_rules.json`、`banned.json`、`advisory_rules.json` 与 `COMMON.md` 的「去 AI 味自检」完整持有。**本库不重复建规则**，仅在 `anti-ai/` 做引用指针。

## 目录导航

| 子目录 | 内容 | 主要调用时机 |
|---|---|---|
| `genre-prose-cards/` | 32 个题材正文提示卡 | 写正文 / 定题材味时，按 `设定/题材定位` 召回 1 张 |
| `hooks/` | 章首 / 章尾 / 悬念 / 段落钩子 | 每章开头与结尾、制造悬念时 |
| `plot-emotion/` | 情节情绪系统 / 反转工具包 / 大纲方法 | 设计大纲、爽点、反转、节奏时 |
| `character/` | 人设基础 / 设计方法 / 关系 | 建人设、配角、反派、感情线时 |
| `deconstruction/` | 拆文方法论（逆向分析） | 用 `tools/story_analyze.py` 拆文库、做对标分析时 |
| `short/` | 短篇专属（写法底座 / 格式 / 题材风格） | 写 1–2 万字短篇时 |
| `anti-ai/` | 去 AI 三遍法 / 禁用词（引用指针） | 自检 / 改写时，指向 `config/` 与 `COMMON.md` |

## 召回原则

1. **按需取用，不全量加载**：写正文时只召回当前题材卡 + 当前钩子类型 + 当前剧情方法，不把整套知识库塞进 prompt。
2. **冲突优先级**（来自源 `genre-prose-cards.md`）：章节细纲与连续性 > 情绪 / 节奏权威 > 题材卡 > 本书文风 > 通用技巧。
3. **题材卡只校准「题材味」**，绝不出现在正文里（不写卡名、题材标签、置信度、合规自评或写作过程说明）。
4. 本库为知识层；确定性拆文骨架由 `tools/story_analyze.py` 生成，LLM 拆文流水线见 `tools/story_analyze.py`。
